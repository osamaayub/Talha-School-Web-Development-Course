## 📝 Adding New Documentation

When adding new documentation to this folder:

1. **Choose the appropriate location**:
   - General course notes → `course-notes.md`
   - External resources → `resources.md`
   - Project-specific guides → `project-name-guide.md`
   - Ebooks/PDFs → `ebooks/` folder
   - Presentations → `slides/` folder
   - Templates → `templates/` folder

2. **Follow naming conventions**:
   - Use lowercase with hyphens for filenames
   - Be descriptive and clear
   - Include date if version-specific

3. **Update this README**:
   - Add new files to the structure above
   - Include brief descriptions
   - Update usage instructions if needed
