# StyleHub - Premium Clothing Collection Landing Page

A modern, responsive landing page for StyleHub, a premium clothing brand featuring contemporary design patterns, interactive features, and seamless user experience.

## 🌟 Project Overview

StyleHub is a fully-featured e-commerce landing page showcasing modern web development practices including responsive design, dark mode support, search functionality, and interactive shopping cart system. The project demonstrates advanced CSS techniques, vanilla JavaScript functionality, and user-centered design principles.

## ✨ Key Features

### Modern Navigation Bar
- **Professional SVG Icons**: Replaced emoji icons with clean, scalable SVG graphics
- **Search Functionality**: Real-time product search with filtering and automatic reset
- **User Account Dropdown**: Interactive dropdown menu with account management options
- **Dark Mode Toggle**: Theme switching with localStorage persistence
- **Mobile Responsive**: Enhanced mobile navigation with search overlay and backdrop

### Interactive Components
- **Shopping Cart System**: Add/remove items, quantity management, persistent cart storage
- **Product Filtering**: Search through products by name and description
- **Scroll Spy Navigation**: Active section highlighting as you scroll
- **Smooth Scrolling**: Seamless navigation between sections
- **Toast Notifications**: User feedback for all interactions

### Design Features
- **Glassmorphism Effects**: Modern backdrop blur and transparency effects
- **Gradient Themes**: Beautiful color gradients for buttons and accents
- **Responsive Grid Layouts**: Adaptive layouts for all screen sizes
- **Hover Animations**: Smooth transitions and micro-interactions
- **Dark Mode Support**: Complete theme switching for all components

## 🔧 Setup and Installation

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for testing)
- Git (for cloning the repository)

### Local Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/osamaayub/Talha-School-Web-Development-Course.git
   ```

2. **Navigate to the project**
   ```bash
   cd WebDevelopmentCourse/CSS/LandingPage
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

4. **Access the site**
   - If using a server: `http://localhost:8000`
   - If opening directly: `file:///path/to/index.html`

The site includes a complete dark mode implementation:
- **Automatic Detection**: Respects system preferences on first visit

- **Persistence**: Theme preference saved in localStorage

- **Mobile Support**: Full-screen search overlay for mobile devices
