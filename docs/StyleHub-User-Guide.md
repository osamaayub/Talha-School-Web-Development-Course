# StyleHub - User Guide

Complete user guide for navigating and using all features of the StyleHub landing page.

## 🌐 Getting Started

### Accessing the Site
- **Live Site**: `https://osamaayub.github.io/Talha-School-Web-Development-Course/`
- **Local Access**: Open `index.html` in your web browser
- **Recommended Browsers**: Chrome, Firefox, Safari, Edge (latest versions)

### First Visit
1. The site will automatically detect your system's theme preference (light/dark mode)
2. All features are ready to use immediately
3. No account registration required for browsing

## 🧭 Navigation Guide

### Main Navigation Bar
The navigation bar is located at the top of the page and includes:

#### Navigation Links
- **Home**: Returns to the hero section
- **Products**: Jump to the featured collection
- **About**: Learn about StyleHub
- **Contact**: Get in touch information

#### Interactive Elements
- **Search Bar**: Search for products
- **User Icon**: Access account menu
- **Theme Toggle**: Switch between light/dark mode
- **Cart Icon**: View shopping cart

### Mobile Navigation
On mobile devices (<768px):
- **Hamburger Menu**: Click the three-line icon to open the menu
- **Slide-in Menu**: Navigation slides in from the right
- **Search Button**: Separate search icon for mobile search overlay
- **Backdrop**: Tap outside menu to close

## 🔍 Search Functionality

### Desktop Search
#### How to Use
1. Click in the search input field in the navigation bar
2. Type your search term (product name or description)
3. Products filter automatically as you type
4. Press Enter or click the search icon to confirm search

#### Keyboard Shortcuts
- **Ctrl/Cmd + K**: Focus the search input
- **Enter**: Execute search
- **Escape**: Clear search and reset results

#### Search Features
- **Real-time Filtering**: Results update as you type
- **Multi-field Search**: Searches both product names and descriptions
- **Auto Reset**: Clear the input to show all products again
- **Result Count**: Shows how many products match your search

### Mobile Search
#### How to Use
1. Tap the search icon in the mobile navigation
2. Full-screen search overlay appears
3. Type your search term
4. Press Enter to search or tap the X to close

#### Mobile Search Features
- **Full-screen Overlay**: Large, touch-friendly input field
- **Close Button**: X button to close the overlay
- **Backdrop Blur**: Smooth visual transition
- **Auto-close**: Closes automatically after search

## 🌙 Dark Mode

### Switching Themes
#### Toggle Button
- Click the sun/moon icon in the navigation bar
- Icon changes to reflect current theme
- Theme switches instantly with smooth transition

#### Theme Persistence
- Your theme preference is saved automatically
- Preference persists across browser sessions
- Site remembers your choice on return visits

#### System Preference
- First visit detects your system's theme preference
- Respects your OS dark/light mode setting
- Can be manually overridden anytime

### Dark Mode Features
- **Complete Coverage**: All sections support dark mode
- **High Contrast**: WCAG compliant color ratios
- **Smooth Transitions**: Animated theme switching
- **Accessibility**: Improved readability in low light

## 🛒 Shopping Cart

### Adding Products to Cart
1. Browse the products section
2. Click "Add to Cart" button on any product
3. Toast notification confirms addition
4. Cart count updates in navigation bar

### Viewing Cart
1. Click the cart icon in the navigation bar
2. Cart modal opens with all items
3. See product details, quantities, and prices
4. View total amount

### Managing Cart Items
#### Quantity Adjustment
- Click **+** button to increase quantity
- Click **-** button to decrease quantity
- Quantity updates automatically
- Cart total recalculates instantly

#### Removing Items
- Click the **×** button next to any item
- Item removed immediately
- Toast notification confirms removal
- Cart count updates accordingly

#### Cart Persistence
- Cart items saved in browser storage
- Cart persists across page refreshes
- Items remain until manually removed
- Works even after closing browser

### Checkout Process
1. Review items in cart
2. Click "Proceed to Checkout" button
3. Currently shows confirmation message
4. Future: Redirect to checkout page

## 🔧 Troubleshooting

### Common Issues

#### Search Not Working
- **Solution**: Clear browser cache and refresh
- **Check**: Ensure JavaScript is enabled
- **Try**: Use a different browser

#### Cart Not Saving
- **Solution**: Check browser localStorage permissions
- **Check**: Browser privacy settings
- **Try**: Incognito mode to test

#### Dark Mode Not Persisting
- **Solution**: Clear browser localStorage
- **Check**: Browser privacy settings
- **Try**: Manually toggle theme again

#### Images Not Loading
- **Solution**: Check internet connection
- **Check**: Image URLs are accessible
- **Note**: Fallback text appears for missing images

#### Mobile Menu Not Opening
- **Solution**: Refresh the page
- **Check**: JavaScript is enabled
- **Try**: Tap the hamburger icon again

### Performance Issues
- **Slow Loading**: Check internet connection
- **Laggy Animations**: Close other browser tabs
- **Memory Issues**: Refresh the page
