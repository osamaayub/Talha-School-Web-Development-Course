## HTML Module Notes

### Basic HTML Structure
- Every HTML document starts with `<!DOCTYPE html>`
- The `<html>` element is the root element
- `<head>` contains metadata and document information
- `<body>` contains visible content

### Important HTML Elements
- **Headings**: `<h1>` through `<h6>` for hierarchical content
- **Paragraphs**: `<p>` for text content
- **Links**: `<a>` for navigation
- **Images**: `<img>` with alt text for accessibility
- **Lists**: `<ul>`, `<ol>`, and `<li>` for organized content
- **Forms**: `<form>`, `<input>`, `<textarea>`, `<button>` for user interaction

### Semantic HTML
- Use semantic elements like `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Improves accessibility and SEO
- Makes code more readable and maintainable

### Meta Tags
- `<meta charset="UTF-8">`: Sets character encoding
- `<meta name="viewport">`: Ensures proper mobile rendering
- `<meta name="description">`: Provides page description for search engines
