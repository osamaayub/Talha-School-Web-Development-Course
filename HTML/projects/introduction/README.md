## 📝 HTML Structure

### Document Outline
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Introduction to HTML</title>
    <link rel="stylesheet" href="styles/intro.css" />
</head>
<body>
    <div class="container">
        <h1>Introduction to Web Development Course</h1>
        <p>Welcome to your journey into web development!</p>
    </div>
</body>
</html>
```

### Key Elements Explained

- `<!DOCTYPE html>`: Declares the document type and HTML version
- `<html lang="en">`: Root element with language attribute
- `<head>`: Contains metadata and document information
- `<meta charset="UTF-8">`: Sets character encoding
- `<meta name="viewport">`: Ensures proper rendering on mobile devices
- `<title>`: Sets the page title (shown in browser tab)
- `<body>`: Contains visible page content
- `<h1>`: Main heading (most important)
- `<p>`: Paragraph text
