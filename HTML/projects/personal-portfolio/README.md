# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing professional information, experience, and contact form.

## 📖 Project Overview

This project is a personal portfolio website designed to showcase professional skills, experience, education, and provide a way for visitors to get in touch through a contact form.

## ✨ Features

- ✅ Modern, responsive design
- ✅ Gradient color scheme
- ✅ Professional sections (About, Experience, Education)
- ✅ Hobbies and interests display
- ✅ Interactive contact form
- ✅ External portfolio link
- ✅ Smooth hover effects
- ✅ Mobile-first responsive design

## 🎯 Learning Outcomes

This project demonstrates:
- Advanced CSS styling techniques
- Form implementation and styling
- Responsive layout design
- CSS gradients and transitions
- Professional web design patterns
- User experience considerations

## 🛠️ Technologies Used

- **HTML5**: Semantic markup, form elements
- **CSS3**: Advanced styling, gradients, transitions, media queries
- **Responsive Design**: Mobile-first approach
- **Modern CSS**: Flexbox, transitions, hover effects

## 🚀 How to View

### Option 1: Direct Browser Opening
1. Navigate to the project directory:
   ```bash
   cd HTML/projects/personal-portfolio
   ```

2. Open `index.html` in your web browser

### Option 2: Local Server
1. Navigate to the project directory:
   ```bash
   cd HTML/projects/personal-portfolio
   ```

2. Start a local server:
   ```bash
   npx serve
   ```

3. Open the provided URL in your browser

## 🔧 Customization

### Personal Information
Edit the following in `index.html`:
- Name and title in the header
- About me content
- Experience details
- Education information
- Hobbies and interests
- Contact form labels

### Styling Changes
Edit `styles/portfolio.css` to customize:
- Color scheme (gradients, accent colors)
- Typography (fonts, sizes)
- Layout (spacing, container width)
- Form styling
- Hover effects and transitions

### Adding Images
1. Place images in `assets/images/`
2. Update image paths in `index.html`
3. Ensure images are optimized for web
4. Add appropriate alt text for accessibility
