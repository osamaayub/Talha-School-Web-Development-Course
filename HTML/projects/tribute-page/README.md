# Tribute Page for Dr. Norman Borlaug

A responsive tribute page honoring Dr. Norman Borlaug, the father of the Green Revolution who saved over a billion lives through his agricultural innovations.

## 📖 Project Overview

This project is a tribute page that showcases the life and achievements of Dr. Norman Borlaug, an American agronomist who led initiatives worldwide that contributed to the extensive increases in agricultural production termed the Green Revolution.

## ✨ Features

- ✅ Responsive design that works on all devices
- ✅ Semantic HTML5 structure
- ✅ Interactive timeline of Dr. Borlaug's life
- ✅ Image with descriptive caption
- ✅ Inspirational quote section
- ✅ External reference links
- ✅ Clean, modern styling with CSS
- ✅ Accessibility considerations

### Timeline Events

## 🔧 Customization

### Modifying Content
- Edit `index.html` to change text content
- Update timeline events in the `<ul>` section
- Modify the quote in the `<blockquote>` section

### Styling Changes
- Edit `styles/main.css` to customize colors, fonts, and layout
- Modify the gradient in the `body` background
- Adjust container width and spacing

- Place images in `assets/images/`
- Update image paths in `index.html`
