Animations in CSS

Twelve small, copy-ready examples using @keyframes, transition, transform and animation-timeline. Hover the cards and read the code beneath each one.

1. Bounce @keyframes

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-60px); }
}
.ball { animation: bounce 1s ease-in-out infinite; }

2. Pulse scale + box-shadow

@keyframes pulse {
  0%   { box-shadow: 0 0 0 0 rgba(99,102,241,.7); }
  100% { box-shadow: 0 0 0 28px rgba(99,102,241,0); }
}
.pulse { animation: pulse 1.6s infinite; }

3. Spinner rotate

@keyframes spin { to { transform: rotate(360deg); } }
.spinner {
  border: 5px solid #334155;
  border-top-color: #6366f1;
  animation: spin .9s linear infinite;
}

4. Shake on hover :hover + animation

@keyframes shake {
  25% { transform: translateX(-6px); }
  75% { transform: translateX(6px); }
}
.shake-btn:hover { animation: shake .4s; }

5. Staggered fade-up animation-delay

First Second Third 
.line {
  opacity: 0;
  animation: fadeUp .6s forwards;
  animation-delay: calc(var(--i) * 150ms);
}

6. Sliding hover fill transition + ::before

.fill-btn::before {
  content: ""; position: absolute; inset: 0;
  transform: translateX(-101%);
  transition: transform .4s ease;
}
.fill-btn:hover::before { transform: none; }

8. Typing effect steps()

Hello, I build things.

.typing {
  width: 22ch; overflow: hidden; white-space: nowrap;
  border-right: 3px solid;
  animation: typing 3s steps(22) infinite alternate,
             blink .7s step-end infinite;
}

9. Gradient text background-position

Moving colors

.shift {
  background: linear-gradient(90deg,#6366f1,#22d3ee,#f472b6,#6366f1);
  background-size: 300% 100%;
  -webkit-background-clip: text; color: transparent;
  animation: shift 4s linear infinite;
}

10. Skeleton shimmer loading state

.sk {
  background: linear-gradient(90deg,#1e293b 25%,#334155 50%,#1e293b 75%);
  background-size: 200% 100%;
  animation: shimmer 1.4s infinite;
}

11. Morphing blob border-radius

@keyframes morph {
  0%,100% { border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%; }
  50%     { border-radius: 30% 60% 70% 40% / 50% 60% 30% 60%; }
}
.blob { animation: morph 6s ease-in-out infinite; }

12. Wave dots staggered loader

.dots i { animation: wave 1s ease-in-out infinite; }
.dots i:nth-child(2) { animation-delay: .12s; }
.dots i:nth-child(3) { animation-delay: .24s; }
.dots i:nth-child(4) { animation-delay: .36s; }

Bonus: scroll-driven animation

The bar at the very top of this page grows as you scroll, with no JavaScript, using animation-timeline: scroll() (supported in current Chrome and Edge; other browsers simply don't show it). 

.page-progress {
  transform: scaleX(0); transform-origin: left;
  animation: grow linear both;
  animation-timeline: scroll(root);
}
@keyframes grow { to { transform: scaleX(1); } }

All motion here switches off for visitors who enable prefers-reduced-motion.
