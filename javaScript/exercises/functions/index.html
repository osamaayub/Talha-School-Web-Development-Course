Coding Exercises

Functions

Practice writing and calling functions with function declarations, parameters, arguments, and return values.

1. Your first function

A function groups code so you can run it again and again by calling its name. Write a function once, call it many times. 

function greet(name) {
  return `Hello, ${name}! Welcome back.`;
}

console.log(greet("Ada"));
// Hello, Ada! Welcome back.
The greeting will appear here.

2. Functions with multiple parameters

Functions can take as many parameters as you need. Pass the arguments in the same order when you call it. 

function triangleArea(base, height) {
  return (base * height) / 2;
}
The area will appear here.

3. Return values vs console.log

return hands a value back to whoever called the function, so you can use it in calculations or pass it to another function. console.log only displays the value. 

function double(number) {
  return number * 2;
}

function square(number) {
  return number * number;
}

console.log(square(double(3))); // 36
The result will appear here.

4. Challenge: discountPrice

Write a function discountPrice(price, percentOff) that returns the price after a percentage discount, rounded to 2 decimal places.

Starter code:

  // your code here
  // remember to return the result!

Click to run the tests.
  • Math.round(number * 100) / 100 rounds to 2 decimal places.
  • A function without a return gives back undefined.
Show the solution 
function discountPrice(price, percentOff) {
  const discount = price * (percentOff / 100);
  return Math.round((price - discount) * 100) / 100;
}
