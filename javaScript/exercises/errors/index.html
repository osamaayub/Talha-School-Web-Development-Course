Errors and Error Handling

Learn to read common JavaScript errors, catch them with try...catch, and throw your own errors with throw.

1. Meet the common errors

Click a button to run broken code safely. Read the error name and message: they tell you what went wrong. 

// ReferenceError: using a variable that doesn't exist
console.log(userName);

// TypeError: using a value the wrong way
const age = 25;
age.toUpperCase();

// TypeError: reading a property of undefined
const user = undefined;
user.name;

// RangeError: a value outside the allowed range
const list = new Array(-1);
Click a button to see the error.

A SyntaxError (like a missing bracket) is different: the browser can't even read the code, so nothing runs and try...catch can't catch it.

2. Catch errors with try...catch

JSON.parse throws an error when the text isn't valid JSON. Without try...catch, the whole script stops. With it, we can show a friendly message instead. 

try {
  const data = JSON.parse(text);
  console.log("Parsed:", data);
} catch (error) {
  console.log("Something went wrong:", error.message);
} finally {
  console.log("This always runs.");
}

Try breaking it: remove a quote or a bracket and parse again.

3. Challenge: throw your own errors

Write a function withdraw(balance, amount) that returns the new balance, but throws an error when:

  1. amount is not a number: throw a TypeError with "Amount must be a number".
  2. amount is 0 or less: throw a RangeError with "Amount must be greater than 0".
  3. amount is more than balance: throw an Error with "Insufficient funds".

Starter code:

function withdraw(balance, amount) {
  // your checks here
  return balance - amount;
}

try {
  console.log(withdraw(100, 30));   // 70
  console.log(withdraw(100, 500));  // throws "Insufficient funds"
} catch (error) {
  console.log(`${error.name}: ${error.message}`);
}

Try 30, -5, 0, 500 and abc.

The result will appear here.
Click to run the tests.
  • Use typeof amount !== "number" or Number.isNaN(amount) for the first check.
  • Put each check in its own if and throw inside it.
  • Code after throw never runs, so the return only happens when all checks pass.
Show the solution 
function withdraw(balance, amount) {
  if (typeof amount !== "number" || Number.isNaN(amount)) {
    throw new TypeError("Amount must be a number");
  }

  if (amount <= 0) {
    throw new RangeError("Amount must be greater than 0");
  }

  if (amount > balance) {
    throw new Error("Insufficient funds");
  }

  return balance - amount;
}
