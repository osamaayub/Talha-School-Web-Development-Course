Coding Exercises

Arrays

Practice storing lists of values, changing them with methods like push and pop, and transforming them with map, filter, and reduce.

1. Access items by index

An array stores items in order, starting at index 0. Use array[index] to read an item and array.length to see how many items it holds. 

const colors = ["red", "green", "blue"];

console.log(colors[0]);     // "red"  (first item)
console.log(colors[colors.length - 1]); // "blue"  (last item)
console.log(colors.length); // 3
The result will appear here.

2. Change an array with push and pop

push() adds items to the end of an array and pop() removes the last item. unshift() adds to the front and shift() removes the first item. 

const queue = ["Ada", "Grace", "Alan"];

queue.push("Katherine");  // ["Ada", "Grace", "Alan", "Katherine"]
queue.pop();               // removes "Katherine"
queue.unshift("Margaret"); // ["Margaret", "Ada", "Grace", "Alan"]
queue.shift();             // removes "Margaret"
The list will appear here.

3. Transform with map and filter

map() creates a new array by applying a function to every item. filter() keeps only the items where the function returns true. 

const prices = [10, 25, 40, 55];

const withTax = prices.map((price) => price * 1.2);
// [12, 30, 48, 66]

const bigOrders = prices.filter((price) => price >= 40);
// [40, 55]
The result will appear here.

4. Challenge: totalPrice

Write a function totalPrice(items) that takes an array of item objects like { name: "Book", price: 15 } and returns the sum of all the prices. 

function totalPrice(items) {
  // use reduce(), or a loop with a running total
  return items.reduce((sum, item) => sum + item.price, 0);
}

const cart = [
  { name: "Book", price: 15 },
  { name: "Mug", price: 8 },
  { name: "Pen", price: 2 },
];

console.log(totalPrice(cart));
// 25
The result will appear here.
Click to run the tests.
  • reduce() visits each item and keeps a running total.
  • Don't forget the starting value 0 as the second argument to reduce().
Show the solution 
function totalPrice(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

// The same thing works with a loop:
function totalPriceWithLoop(items) {
  let total = 0;

  for (const item of items) {
    total += item.price;
  }

  return total;
}
