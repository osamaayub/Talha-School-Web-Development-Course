Loops

Practice repeating code with for, while, and for...of loops, then solve the FizzBuzz challenge.

1. Multiplication table with a for loop

A for loop is best when you know how many times to repeat.

for (let i = 1; i <= 10; i++) {
  console.log(`${number} x ${i} = ${number * i}`);
}

2. Countdown with a while loop

A while loop keeps running as long as its condition is true. Don't forget to change the counter, or the loop never stops! 

let count = start;

while (count > 0) {
  console.log(count);
  count--;
}

console.log("Liftoff!");

3. Count vowels with for...of

for...of loops through each item in a string or array, one at a time. 

let vowels = 0;

for (const letter of word.toLowerCase()) {
  if ("aeiou".includes(letter)) {
    vowels++;
  }

4. Challenge: FizzBuzz

Write a function fizzBuzz(n) that loops from 1 to n and returns an array where:

  1. Numbers divisible by 3 become "Fizz".
  2. Numbers divisible by 5 become "Buzz".
  3. Numbers divisible by both 3 and 5 become "FizzBuzz".
  4. Every other number stays as it is.

Starter code:

function fizzBuzz(n) {
  const result = [];
  // your loop here
  return result;
}

console.log(fizzBuzz(5));
// [1, 2, "Fizz", 4, "Buzz"]

console.log(fizzBuzz(15).at(-1));
// "FizzBuzz"

Click to run the tests.
  • Use the % (remainder) operator to check if a number divides evenly.
  • Check "divisible by both" first, otherwise "Fizz" will win.
Show the solution 
function fizzBuzz(n) {
  const result = [];

  for (let i = 1; i <= n; i++) {
    if (i % 3 === 0 && i % 5 === 0) {
      result.push("FizzBuzz");
    } else if (i % 3 === 0) {
      result.push("Fizz");
    } else if (i % 5 === 0) {
      result.push("Buzz");
    } else {
      result.push(i);
    }
  }

  return result;
}
