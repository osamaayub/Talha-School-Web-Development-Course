Coding Exercises

Objects

Practice storing data in key-value pairs, reading and changing properties, and working with nested objects and methods.

1. Read properties with dot and bracket notation

Objects store values under named keys. Use object.key or object["key"] to read a value, and the same syntax to change it. 

const user = {
  name: "Ada",
  age: 36,
  city: "London",
};

console.log(user.name);        // "Ada"
console.log(user["age"]);      // 36
user.city = "Paris";           // update a property
console.log(user.city);        // "Paris"
The result will appear here.

2. Add properties and nest objects

You can add new keys at any time, and a value can itself be an object. Access nested values by chaining the keys. 

const profile = {
  name: "Grace",
  address: {
    city: "New York",
    zip: "10001",
  },
};

profile.job = "Admiral";          // add a new key
console.log(profile.address.city); // "New York"
console.log(profile.address.zip);  // "10001"
The result will appear here.

3. Methods and Object.keys / values

An object can hold functions as values. Call them with object.method() and use this to reach the object's own properties. 

const counter = {
  count: 0,
  increment() {
    this.count++;
  },
};

counter.increment();
counter.increment();
console.log(counter.count); // 2

console.log(Object.keys(counter));   // ["count", "increment"]
console.log(Object.values({ a: 1, b: 2 })); // [1, 2]
The result will appear here.

4. Challenge: describeUser

Write a function describeUser(user) that takes an object like { name: "Ada", age: 36, city: "London" } and returns a sentence: "Ada is 36 years old and lives in London." 

function describeUser(user) {
  return `${user.name} is ${user.age} years old and lives in ${user.city}.`;
}

console.log(describeUser({ name: "Ada", age: 36, city: "London" }));
// "Ada is 36 years old and lives in London."
The result will appear here.

function describeUser(user) {

// A loop-based version works too:
function describeUserLong(user) {
  return (
    user.name +
    " is " +
    user.age +
    " years old and lives in " +
    user.city +
    "."
  );
}
