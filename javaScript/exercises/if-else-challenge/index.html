If/Else Challenge: Movie Ticket Price

Use if, else if, and else to work out the right ticket price for each customer.

1. The rules

Write a function getTicketPrice(age, isStudent, day) that returns the ticket price:

  1. Kids under 5 get in free ($0).
  2. Kids aged 5 to 12 pay $8.
  3. Seniors aged 65 and up pay $7.
  4. Everyone else pays $12.
  5. Students (13 to 64) get $3 off the regular price.
  6. On Tuesday, every paid ticket gets $2 off. The price can never go below $0.

  // your code here

console.log(getTicketPrice(20, true, "Sunday"));   // 9

console.log(getTicketPrice(35, false, "Tuesday")); // 10

4. Hints and solution

  • Check the age ranges from youngest to oldest so the conditions don't overlap.
  • Handle the student discount only inside the "everyone else" branch.
  • Apply the Tuesday discount last, after the base price is set.
Show the solution 
function getTicketPrice(age, isStudent, day) {
  let price;

  if (age < 5) {
    price = 0;
  } else if (age <= 12) {
    price = 8;
  } else if (age >= 65) {
    price = 7;
  } else {
    price = isStudent ? 9 : 12;
  }

  if (day === "Tuesday" && price > 0) {
    price = Math.max(price - 2, 0);
  }

  return price;
}
