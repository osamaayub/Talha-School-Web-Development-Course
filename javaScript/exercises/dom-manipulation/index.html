Coding Exercises

DOM Manipulation

Practice selecting elements with querySelector, changing their text with textContent, building new elements with createElement, and reacting to clicks.

1. Select an element and read its text

document.querySelector() finds the first element that matches a CSS selector. .textContent reads or changes the text inside an element. 

const heading = document.querySelector("#greeting");
console.log(heading.textContent); // "Hello, learner!"
The result will appear here.

2. Change text and styles

Set .textContent to replace an element's text, or use .style and .classList to change how it looks. 

const banner = document.querySelector("#banner");
banner.textContent = "New message";
banner.style.color = "#b91c1c";
banner.classList.add("highlight");
Original banner text

3. Create and append elements

document.createElement() makes a new element. Use append() or appendChild() to add it to the page, and remove() to delete it. 

const item = document.createElement("li");
item.textContent = "Buy milk";
list.append(item);

item.remove(); // removes it from the page

4. Toggle a class with classList

classList.toggle() adds a class if it is missing and removes it if it is already there. CSS rules then change the style. 

const card = document.querySelector("#card");

card.addEventListener("click", () => {
  card.classList.toggle("dark");
});

5. Count clicks with addEventListener

addEventListener("click", ...) runs a function every time the element is clicked. Keep a counter in a variable to track how many clicks happened. 

let clicks = 0;

button.addEventListener("click", () => {
  clicks += 1;
  output.textContent = `Clicked ${clicks} times`;
});
Clicked 0 times

6. Challenge: build a mini list app

Combine everything: read a value from the input, create a new li element for it, give each item a delete button, and append it to the list. 

function addItem(text) {
  const li = document.createElement("li");
  li.textContent = text;

  const deleteButton = document.createElement("button");
  deleteButton.textContent = "Delete";
  deleteButton.addEventListener("click", () => li.remove());

  li.append(deleteButton);
  list.append(li);
}
