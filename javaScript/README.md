# JavaScript Basics

Open `index.html` in a browser to run the interactive JavaScript basics module.

Topics covered:

- Variables with `let` and `const`
- Primitive and complex data types
- Arithmetic and comparison operators
- `if`, `else if`, and `else`
- `for` loops
- Functions
- Arrays
- Objects
- String literals, quotes, and template literals
- DOM selection and events
- Type coercion in arithmetic operations

## Coding exercise

### [Basic Calculator](exercises/basic-calculator/)

Uses variables, number values, arithmetic operators, comparison, and form events.
Enter two numbers to calculate:

- Sum
- Difference
- Product
- Quotient
- Remainder

### [String Literals](exercises/string-literals/)

Practice single- and double-quoted strings, escaping quote characters,
concatenation, and template literals with embedded values and multiple lines.

### [If/Else Challenge](exercises/if-else-challenge/)

Work out movie ticket prices with `if`, `else if`, and `else`. Covers age
ranges, a student discount, and a Tuesday discount, with test cases, hints,
a hidden solution, and bonus challenges.

### [Loops](exercises/loops/)

Practice `for`, `while`, and `for...of` loops with a multiplication table,
a countdown, and a vowel counter, then solve the FizzBuzz challenge with
test cases, hints, a hidden solution, and bonus challenges.
