# JavaScript Basics

Open `index.html` in a browser to run the interactive JavaScript basics module.

Topics covered:

- Variables with `let` and `const`
- Primitive and complex data types
- Arithmetic and comparison operators
- `if`, `else if`, and `else`
- `for` loops
- Functions
- Arrays
- Objects
- String literals, quotes, and template literals
- DOM selection and events
- Type coercion in arithmetic operations

## Coding exercise

### [Basic Calculator](exercises/basic-calculator/)

Uses variables, number values, arithmetic operators, comparison, and form events.
Enter two numbers to calculate:

- Sum
- Difference
- Product
- Quotient
- Remainder

### [String Literals](exercises/string-literals/)

Practice single- and double-quoted strings, escaping quote characters,
concatenation, and template literals with embedded values and multiple lines.

### [If/Else Challenge](exercises/if-else-challenge/)

Work out movie ticket prices with `if`, `else if`, and `else`. Covers age
ranges, a student discount, and a Tuesday discount, with test cases, hints,
a hidden solution, and bonus challenges.

### [Loops](exercises/loops/)

Practice `for`, `while`, and `for...of` loops with a multiplication table,
a countdown, and a vowel counter, then solve the FizzBuzz challenge with
test cases, hints, a hidden solution, and bonus challenges.

### [Functions](exercises/functions/)

Practice function declarations, parameters, arguments, and return values with
a greeting generator, a triangle area calculator, and nested function calls,
then solve the `discountPrice` challenge with test cases, a hidden solution,
a quiz question, and bonus challenges.

### [Arrays](exercises/arrays/)

Practice indexing and `length`, changing arrays with `push`, `pop`, `unshift`,
and `shift`, transforming them with `map` and `filter`, then solve the
`totalPrice` challenge with `reduce`, with test cases, a hidden solution, a
quiz question, and bonus challenges.

### [Objects](exercises/objects/)

Practice reading properties with dot and bracket notation, adding keys,
nesting objects, methods with `this`, and `Object.keys`/`values`, then solve
the `describeUser` challenge with template literals, with test cases, a
hidden solution, a quiz question, and bonus challenges.

### [Errors](exercises/errors/)

Meet ReferenceError, TypeError, RangeError and SyntaxError, catch errors with
`try...catch...finally`, and throw your own errors in a `withdraw` challenge
with test cases, a bug-fix question, a hidden solution, and bonus challenges.

### [DOM Manipulation](exercises/dom-manipulation/)

Practice `querySelector`, `textContent`, `createElement` and `append`,
`classList.toggle`, and `addEventListener` with interactive examples: reading
and changing text, styling a banner and card, building a to-do list with
delete buttons, a click counter, a mini list app challenge, a quiz question,
and bonus challenges.

### [Quote Generator](exercises/quote-generator/)

Generate random inspirational quotes and copy the selected quote to the
clipboard. This project combines arrays, random selection, DOM updates,
events, CSS transitions, and the Clipboard API.

### [Age Calculator](exercises/age-calculator/)

Calculate age in years, months, and days, plus the time until the next birthday.
Practice date inputs, calendar arithmetic, validation, and accessible DOM updates.
