JavaScript Basics Module

Learn JavaScript step by step

Read each example, run it, and change the code to experiment.

1. Variables

let creates a value that can change. const creates a value that cannot be reassigned.

2. Data types

JavaScript values can be strings, numbers, booleans, arrays, objects, null, or undefined.

3. Operators

Arithmetic operators calculate values. Comparisons return true or false.

4. Conditions

if, else if, and else choose which code should run.

5. Loops

Loops repeat code. A for loop runs a known number of times.

6. Functions

Functions group reusable code and can accept parameters and return results.

7. Arrays

Arrays store ordered lists of values.

8. Objects

Objects store related data as named properties.

9. DOM and events

JavaScript can change page elements and respond when a user interacts.
